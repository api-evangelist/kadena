Background Marmalade is an NFT smart contract system in Kadena’s blockchain, which is simply a system of multiple contracts that programs and runs logic configured by the token policies that the token is built with. Marmalade has been in action for several years, and now we’ve diligently upgraded to Marmalade V2, encapsulating an entirely new system and simplifying the process of engaging with NFTs. Most excitingly, Marmalade V2 is now live on testnet !
